# CodeSharks - HardwareBase

A full-stack PC building information and recommendation platform which allows users to explore hardware components, create custom PC builds, check compatibility, and estimate gaming performance based on real-world requirements to help users make informed decisions.

## 🚀 Features:

### 🖥️ PC Builder

* Custom PC build creation
* Real-time compatibility checking
* Power consumption estimation
* Price calculation
* Save and manage builds

### 🎮 Game Performance Analyzer

* Compare builds against game requirements
* Estimated FPS at different settings and resolutions
* Performance ratings and recommendations
* Game requirement database

### ⚙️ Hardware Analysis

* Hardware database
* Component vs component comparison
* Price-to-performance analysis

### 👥 Community Features

* User dashboard
* Share builds
* Reviews and discussions

## 🛠️ Tech Stack:

* __Frontend:__ HTML, TailwindCSS, JavaScript
* __Backend:__ Python, Django
* __Database:__ PostgreSQL
